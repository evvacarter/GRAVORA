 GRAVORA

>---Explore the mystery of black holes and the universe beyond---

GRAVORA is an interactive and responsive website created to explore the fascinating world of black holes through an immersive cosmic-themed interface.

The project focuses on presenting information about black holes in a visually engaging way while experimenting with modern web development techniques, responsive layouts, animations, and interactive elements.

 About The Project

GRAVORA is a multi-section informational website centered around the mystery of black holes

The website introduces different concepts related to black holes, including:

- Extreme gravity
- Event horizons
- Black hole rotation
- Growth of black holes
- Stellar black holes
- Supermassive black holes
- Intermediate black holes
- The possibility of undiscovered black holes

The main goal of the project was not only to create an informational website, but also to experiment with web design, responsive layouts, animations, and visual storytelling 

---

feature & Black Hole Hero Animation

The hero section includes an attempt to create a sky / black-hole themed animation using JavaScript.

JavaScript was used to experiment with dynamic visual effects and make the opening section more interactive instead of keeping it completely static.



 Cosmic Visual Design

The website uses a dark cosmic visual style based mainly around:

- Midnight blue
- Deep purple
- Neon purple
- Blue atmospheric glow
- Dark space backgrounds

The visual design was created to maintain a consistent space/black-hole theme throughout the website.


  Black Hole Information

The website contains informational cards explaining different characteristics of black holes.

Some of the topics covered include:

- Extreme Gravity
- No Light Escapes
- Black Hole Rotation
- Black Hole Growth
- Event Horizon
- Their Role in the Universe


 Different Types of Black Holes

GRAVORA also introduces different categories of black holes:

- Stellar Black Holes**
- Supermassive Black Holes
- Intermediate Black Holes

Each type is presented using dedicated visual cards and descriptive content.



  Responsive Design

A major part of this project was making the website responsive.

Considerable effort was spent using CSS Grid, Flexbox, media queries, fixed card sizing, spacing, alignment, and responsive breakpoints so that the layout works across:

- Desktop
- Laptop
- Tablet
- Mobile devices

The card layouts automatically adapt to smaller screen sizes instead of overflowing or becoming distorted.

  Design & Development

One of the biggest learning experiences from this project was understanding how different sections of a website interact with each other.

A significant amount of time was spent improving:

- Card alignment
- Responsive layouts
- Desktop layouts
- Mobile layouts
- Spacing between sections
- Image sizing
- Text positioning
- Grid layouts
- Overall visual consistency

The project helped me understand that creating a responsive website requires more than simply making elements smaller. Layout structures, spacing, sizing, and breakpoints all need to work together.
